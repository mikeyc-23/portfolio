# Mikey Corrado — Portfolio

A terminal-themed personal portfolio built with React, TypeScript, and SCSS.

## Stack

- **React 19** + TypeScript
- **Vite** for builds
- **SCSS** with BEM methodology
- **JetBrains Mono** typeface

## Features

- CRT-style green-on-black terminal aesthetic with scanline overlays
- Animated entry screen with Matrix rain background
- Build transition sequence that mimics a terminal compile
- Scroll-spy tab navigation tracking active section
- Skills ticker with infinite horizontal scroll
- Project cards with CRT-filtered preview images
- Blog section with search, modal reader, and fullscreen mode
- Contact section with boot sequence animation
- Fully responsive down to mobile

## Local Development

```bash
cd client
npm install
npm run dev
```

## Deployment

Deployed on [Vercel](https://vercel.com). The root directory is set to `client/`.
