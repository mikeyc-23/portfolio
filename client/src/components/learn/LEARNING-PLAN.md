# React + TypeScript Learning Plan

Learn by building real features into the portfolio. Each feature targets specific concepts.

## Feature Roadmap

### Feature 1: Live Status Bar Clock
Make the static status bar dynamic with a live-updating clock.
**Concepts:** components, useState, useEffect + cleanup, TypeScript basics
**Status:** ⬜

### Feature 2: Terminal Command Input
Add a real command input bar at the bottom — type commands, get responses.
**Concepts:** controlled inputs, TypeScript interfaces, conditional rendering, event handling, lists + .map()
**Status:** ⬜

### Feature 3: Wire Commands to the App
Commands navigate sections, show help, toggle things. Input talks to parent.
**Concepts:** lifting state, props as callbacks, refs, DOM interaction
**Status:** ⬜

### Feature 4: Persisted Command History
Up-arrow recalls previous commands. History survives across sessions.
**Concepts:** custom hooks, localStorage, useRef for key handling
**Status:** ⬜

### Feature 5: Theme System
Add a `theme` command that switches color palettes across the whole site.
**Concepts:** React Context, CSS variables from JS, TypeScript enums/unions
**Status:** ⬜
